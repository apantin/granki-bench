# Эталоны пилота Granki, 2026-11

Тексты, которые сравнивали судьи в пилоте Granki, посты-эталон голоса и данные. Всё вымышленное: тексты писали модели в ходе пилота, посты — модель при подготовке стенда, данные сгенерированы скриптом.

| Файл | Что |
|---|---|
| `manifest.csv` | Каждый файл набора: путь, sha256, число слов, роль, тема, что за версия |
| `topics.json` | Темы: описание читателя, посты-эталон, данные |
| `pairs.json` | 31 пара пилота: тексты A и B, тема, файл результата в `results/v1-pilot-2026-11/` |
| `texts/` | Версии статей и базы для сравнения |
| `posts/` | Посты-эталон голоса по темам |
| `data/` | Данные, которые видел судья абсолютной оценки |

Проверить хеши: `python3 -m bench verify anchors/pilot-2026-11`. Повторить пару пилота: `python3 -m bench pair --anchors anchors/pilot-2026-11 --pair E5-vs-E4 --out result.json`.

Набор заморожен: файлы не меняются, новые версии текстов — новым набором.
