# Числовая конкретика quantity-v2

Историческая `mutate(..., 'specificity', ...)` версии corrupt-v1 всегда вставляет «несколько». После родительного управления это может добавить грамматическую ошибку: «более 40 минут» → «более несколько минут». Такая пара не является чистым контролем конкретики. Старый алгоритм сохранён для воспроизводимости уже созданных файлов.

Новая `mutate_quantity_v2(text, dose, seed)` использует отдельный ID `quantity-v2`. Замена допускается только после явно перечисленного локального управления: например, «более/до/для/в течение» → «нескольких», «через/за/на/в» → «несколько». Остальные контексты пропускаются. Нулевое количество, календарные годы с «году/года» и имена не заменяются; синтаксическое управление через перенос строки не угадывается. Доза считается по подходящим числовым местам, seed воспроизводим.

Это ограниченное правило, не полный морфологический или смысловой разбор. Падежное исправление не доказывает нейтральность остальных изменений, сохранение стиля, чистоту цитаты или человеческое предпочтение. У новых пар сохраняется предварительная метка по конструкции; пригодность для отдельных проверок оценивается отдельно. Явно ошибочные старые пары должны иметь диагностическое назначение и исключаться из проверки одной оси; исходные файлы не переписываются.
