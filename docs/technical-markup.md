# Кандидат сохранения технической разметки

`bench.candidates.technical_markup.extract(content, url)` — отдельный opt-in
`clean-v20-technical-markup-candidate` поверх v19. Прежние функции и default-v3
сохраняются. Модуль не делает сетевых запросов и не принимает текст в корпус.

HTML-индексы раньше сливались с соседними цифрами: `0,2<sup>3</sup>` превращалось
в `0,23`. Новый кандидат сохраняет отношение как `0,2^(3)`, а `H<sub>2</sub>O`
как `H_(2)O`. Значение не вычисляется, исходное выражение не исправляется.
Обрабатываются только непустые одноуровневые sup/sub без дочерних элементов
и внутренних переводов строки. Ссылки на сноски, вложенное оформление и другие
неоднозначные варианты остаются с `unresolved_super_subscript_nodes`.
Индексы в прямоугольных текстовых таблицах сохраняются тем же способом.

Самостоятельный `code.highlight` с одним `div.wrapper` и последовательными
строками `div.l.l1`, `div.l.l2`, … становится одним `[КОД]`. Внутри строки
допустимы только текст, span и разрывы; собственный текст рядом с обёрткой
запрещён. Такой блок учитывается в `code_blocks` один раз. Сохраняются хвост
и окружающая авторская проза. Существующий pre не обрабатывается повторно.
Однострочные команды в прозе и inline-code остаются текстом; команда не
распознаётся по словарю или по внешнему виду. Неизвестный блок внутри code
сохраняется с `unresolved_highlighted_code`.

Ремонт ограничен однозначно выбранным телом статьи. Сначала используется
первичная издательская область, затем прежние явные DOM-профили. Навигация,
подписи, чужие блоковые цитаты и боковые области не служат материалом ремонта.
При fallback извлечение остаётся прежним, а наличие потенциально значимой
разметки отмечается `unresolved_technical_markup_scope`. Шапка и отдельный
анонс этим кандидатом не преобразуются.

Счётчики `preserved_superscripts`, `preserved_subscripts` и
`masked_highlighted_code` описывают выполненный ремонт. Нулевые unresolved
не доказывают авторство, подходящий жанр, полноту платного источника, отсутствие
чужой речи или независимость от изображений. Эти вопросы требуют отдельной QC.
