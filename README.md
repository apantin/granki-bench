# granki-bench

Бенчмарк русского текста по двум осям: **стиль** (насколько текст похож на тексты автора или жанра) и **качество** (ясность, логика, точность, польза читателю — независимо от стиля). Оси не сводятся в одно число: плохой текст в стиле автора остаётся текстом автора, но отчёт говорит, что он плохой.

**Статус: разработка, протокол не заморожен.** Оценки этой версии не сравнимы с будущими.

## Принципы

- Протоколы оценки с версиями. Выпущенный протокол не меняется, любая правка — новая версия.
- Судьи по умолчанию — общедоступные модели Claude и Codex через CLI. Результат не должен зависеть от того, какой моделью судили: разброс оценок между моделями — метрика наравне с самими оценками.
- Сравнимость держится на замороженных текстах и детерминированных метриках, а не на сохранённых числах судей.
- В каждом результате — версия протокола, хеш промпта, модели, версии CLI, хеши текстов, версия корпуса.

## Данные

Публичный корпус — в отдельном репозитории [granki-corpus](https://github.com/apantin/granki-corpus): у каждого текста свой источник и лицензия. Путь к данным передаётся параметром.
