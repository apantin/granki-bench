# Результаты

Каждый файл — один прогон: парное сравнение (`pair-*.json`) или абсолютная оценка (`score-*.json`).

| Поле | Что |
|---|---|
| `kind` | `pairwise` или `absolute` |
| `protocol`, `prompt_sha256` | Версия протокола и хеш промпта |
| `created`, `bench_commit` | Когда и каким коммитом bench получено |
| `judges`, `cli` | Судьи и версии CLI |
| `inputs` | Тексты с путями, sha256 и числом слов; читатель; посты-эталон |
| `votes` | Голоса: судья, точная модель (`model_id`), порядок, вердикт по критериям, «почему» |
| `a_minus_b` / `mean` | Итог: счёт от −1 до +1 по критериям или средние баллы |
| `spread` | Разброс между моделями: счёт каждой модели и стандартное отклонение по моделям |
| `imported` | `true` — результат перенесён из пилота, а не получен bench |
