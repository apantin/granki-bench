# Протокол v1

Протокол, которым оценивали статьи в пилоте [Granki](https://github.com/apantin/granki) 2026-11-21 — 22. Перенесён как есть: промпты дословно, вместе с недостатками, чтобы результаты пилота оставались сравнимыми. Исправления пойдут в `v2`. Описание метода и выводы пилота — в `docs/dev/evaluation.md` и `docs/dev/pilot.md` репозитория Granki.

| Файл | Что |
|---|---|
| `protocol.json` | Критерии, порядок, формула счёта, судьи, команды запуска |
| `pairwise.prompt.txt` | Промпт слепого парного сравнения |
| `absolute.prompt.txt` | Промпт абсолютной оценки по шкале 1–10 |

Хеши промптов bench записывает в каждый результат.

## Как устроен

- **Парное сравнение.** Судья видит описание читателя, старые посты автора как эталон голоса и две версии текста под метками `text1` и `text2`. По каждому критерию отвечает «1», «2» или «=» и даёт два предложения «почему». Каждый судья сравнивает пару дважды, в порядке AB и BA. Четыре судьи — 8 голосов. Счёт по критерию: (за A − за B) / 8, от −1 до +1.
- **Абсолютная оценка.** Судья видит читателя, посты автора, данные и статью; ставит баллы 1–10 по пяти критериям и перечисляет цитаты признаков нейротекста, проблемы и сильные места.
- **Судьи:** `opus`, `sonnet`, `haiku` через Claude Code (`claude -p`, без инструментов), `codex` через Codex CLI (`codex exec`, только чтение).

## Известные недостатки

Не исправлены намеренно — это `v1`.

- **Ложь судье.** В промпте посты-эталон названы «написаны человеком», а в пилоте их написала модель.
- **Свои судят своих.** Три судьи из четырёх — Claude; в пилоте писал тексты тоже Claude.
- **Длина не учитывается.** Версии отличались по объёму на 10–20%.
- **Модели — псевдонимы.** В пилоте записывались только `opus`, `sonnet`, `haiku`, `codex`, без версий моделей и CLI. bench записывает точные модели в новых прогонах; у импортированных результатов пилота они неизвестны.
- **Системный промпт CLI.** `claude -p` добавляет к промпту судьи системный промпт Claude Code; `codex exec` — свой. Он меняется вместе с версией CLI.
- **Шум ±0,5.** Один прогон на пару; повтор тех же судей на тех же текстах давал расхождение до 0,5.
- **Абсолютные баллы различают плохо:** посты-эталон получили «человечность» 6,75 из 10, тексты моделей — 5–7.
